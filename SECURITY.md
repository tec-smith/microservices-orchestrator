# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's
[security advisory form](https://github.com/tec-smith/microservices-orchestrator/security/advisories/new),
not in a public issue. Include steps to reproduce and the impact you expect.
You'll get an acknowledgement within a few days.

## Scope

This policy covers the framework itself. If you've built a system with it,
you are responsible for that system's security, including protecting the
registry API, which has no authentication of its own. See the README's
[security section](README.md#security) and
[production checklist](README.md#before-going-to-production).
